### 🧬 Architectural Highlights

* 🛰️ **[Alveris GeoAI](https://github.com/pravinkumardatafreak/alveris-geo-ai):** 13-band Sentinel-2 multi-spectral PyTorch CNN + Copernicus DEM 8-way flood fill + InSAR subsidence translated into Basel III Loan-to-Value (LTV) haircut pricing.
* 🧬 **[HuBMAP Segmentation](https://github.com/pravinkumardatafreak/HuBMAP-Tissue-Unit-Segmentation-SOTA):** Organ-Prompted Swin-TransUNet (**0.6782 Dice**) with automated Macenko optical stain normalization for gigapixel histopathology scans.
* 🔮 **[CryptoCast](https://github.com/pravinkumardatafreak/cryptocast):** Multi-horizon price & volatility forecasting benchmarking **PatchTST**, vanilla Transformers, 1D-CNNs, and BiLSTMs with strict walk-forward cross-validation.
* 🎓 **[ERIA Education Analyzer](https://github.com/pravinkumardatafreak/ERIA-Education-Analyzer):** Self-correcting multi-agent loop with Groq-hosted LLaMA 3.3 70B for UGC/AICTE regulatory policy parsing.
* 📊 **[Nifty 50 Market Pipeline](https://github.com/pravinkumardatafreak):** Automated equity time-series store (SQLAlchemy + SQLite) coupled with LLM financial briefing synthesis.
* 🏃 **[Fitbit Calorie Analytics](https://github.com/pravinkumardatafreak/Fitbit-Calorie-Burn-Prediction-Workout-Pattern-Clustering-):** Supervised predictive calorie regression (**R² = 0.9979**) combined with PCA and K-Means metabolic regime clustering.
